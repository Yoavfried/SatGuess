# Font notices

SatGuess self-hosts Hebrew and Latin WOFF2 subsets of these fonts:

- **Fredoka**, used for headings and the brand. Copyright 2016 The Fredoka Project Authors. [Exact upstream OFL notice](Fredoka-OFL.txt); [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/fredoka).
- **Rubik**, used for body text and controls. Copyright 2015 The Rubik Project Authors. [Exact upstream OFL notice](Rubik-OFL.txt); [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/rubik).

Both families use the SIL Open Font License 1.1. The OFL permits embedding and redistribution with the required copyright and license notice. The font software retains OFL 1.1 rather than the application's MIT license. No font is sold as a standalone product by this repository. The bundled WOFF2 subsets are for the interface; font files and corresponding notices must be kept together in redistributed source and website packages.

Operating-system fallback fonts are not redistributed. The road map has no text/symbol layers and does not load the original map style's font glyphs.
